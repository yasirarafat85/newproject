# Phase 3: "মানুষ লাগবে" তালিকা

যেসব কমেন্টে আপনার দেখা দরকার, সেগুলো প্যানেলের **মানুষ লাগবে** পেজে জমা হয়।
বাম মেনুতে লাল সংখ্যাটা দেখায় কয়টা কমেন্ট অপেক্ষায় আছে।

## আপডেট আনা
cPanel → **Git Version Control** → **Update from Remote**, তারপর Terminal-এ:
```bash
cd ~/repos/newproject/fb-bot
php bin/setup.php        # নতুন ডাটাবেস কলাম যোগ হবে
php tests/run.php        # All tests passed.
```

## তিনটা ট্যাব

| ট্যাব | কী থাকে | আপনি যা করতে পারেন |
|---|---|---|
| **উত্তর দিতে হবে** | AI উত্তর জানত না, অথবা কাস্টমার অভিযোগ করেছে বা মানুষ চেয়েছে। AI ইতিমধ্যে একটা ভদ্র "আমরা যোগাযোগ করব" উত্তর দিয়ে রেখেছে। | নিজে উত্তর লিখে **উত্তর পোস্ট করুন**, অথবা ইনবক্স বা ফোনে সমাধান করে **সমাধান হয়েছে** দিন |
| **অনুমোদনের অপেক্ষায়** | DRY_RUN চালু থাকার সময় AI-এর বানানো উত্তর, যা এখনো পোস্ট হয়নি | দরকার হলে এডিট করে **অনুমোদন দিয়ে পোস্ট**, অথবা **পোস্ট না করে বাদ দিন** |
| **ব্যর্থ** | কোনো এররের কারণে উত্তর যায়নি (যেমন AI সাময়িকভাবে ব্যস্ত ছিল, বা Facebook permission নেই) | কারণ দেখে **আবার চেষ্টা**, অথবা নিজে উত্তর লিখুন |

## যা জানা ভালো
- আপনার লেখা উত্তর **পেজের নামে** কমেন্টের নিচে পোস্ট হয়।
- একই কমেন্টে দুবার ক্লিক করলেও বা দুইটা ট্যাবে খোলা থাকলেও **একবারই পোস্ট হবে**।
- Facebook এরর দিলে আপনার লেখা মুছে যাবে না। এররটা উপরে দেখাবে, ঠিক করে আবার চাপতে পারবেন।
- "আবার চেষ্টা"-তে ২৪ ঘণ্টার বেশি পুরনো কমেন্টেরও উত্তর যাবে, কারণ এখানে আপনি নিজে চেয়েছেন।
- কমেন্ট পেজে কে উত্তর দিয়েছে সেটা দেখা যায়: AI নিজে, আপনার অনুমোদনে, নাকি আপনি নিজে লিখেছেন।

## একটা সুবিধাজনক পদ্ধতি
শুরুর কয়েক দিন **DRY_RUN চালু রাখুন** আর দিনে ২–৩ বার "অনুমোদনের অপেক্ষায়" ট্যাব দেখে উত্তর অনুমোদন করুন।
বেশিরভাগ উত্তর কোনো এডিট ছাড়াই ঠিক থাকলে DRY_RUN বন্ধ করে দিন।
