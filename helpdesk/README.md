# HelpDesk 🎫

সম্পূর্ণ বাংলা হেল্পডেস্ক টিকেটিং সিস্টেম — **নেটিভ PHP 8.2+ · MySQL · Vanilla JS**।
কোনো ফ্রেমওয়ার্ক নেই, কোনো build step নেই — XAMPP-এ ফাইল কপি করলেই চলে।

> আর্কিটেকচারের পূর্ণ বিবরণ: [`../docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md)

## বর্তমান অবস্থা

| ফেজ | কাজ | অবস্থা |
|---|---|---|
| **P0** | কোর ফ্রেমওয়ার্ক · ডেটাবেস স্কিমা · ইনস্টলার · অথেনটিকেশন · ড্যাশবোর্ড | ✅ সম্পন্ন |
| **P1** | টিকেট CRUD · ক্লায়েন্ট পোর্টাল · এজেন্ট কিউ ও টিকেট ভিউ · থ্রেড · অ্যাটাচমেন্ট | ✅ সম্পন্ন |
| **P2** | অ্যাডমিন প্যানেল — এজেন্ট · ডিপার্টমেন্ট · টিম · রোল ও পারমিশন · টপিক · সেটিংস · লগ | ✅ সম্পন্ন |
| **P3** | ট্রান্সফার / ফরওয়ার্ডিং · অটো-অ্যাসাইনমেন্ট · কোলাবোরেটর · টাইমলাইন | ✅ সম্পন্ন |
| P4 | ইমেইল পাইপলাইন (IMAP ফেচ · SMTP কিউ) | ⏳ পরবর্তী |
| P5–P8 | SLA · কাস্টম ফর্ম · নলেজ বেস · REST API | ⏳ |

### এখন যা কাজ করে

**গ্রাহক** — অ্যাকাউন্ট সহ বা ছাড়াই টিকেট খোলা · ফাইল সংযুক্ত করা · থ্রেডে উত্তর
দেওয়া · টিকেট নম্বর ও ইমেইল দিয়ে অবস্থা দেখা · নিজের টিকেটের তালিকা

**এজেন্ট** — ছয়টি ফিল্টারে কিউ (চলমান · আমার · আনঅ্যাসাইনড · সময় পার ·
অপেক্ষায় · বন্ধ) · খোঁজা ও সাজানো · তিন-কলামের টিকেট ভিউ · উত্তর ও
ইন্টার্নাল নোট · তৈরি উত্তর বসানো · দায়িত্ব নেওয়া · স্ট্যাটাস ও প্রায়োরিটি
বদল · গ্রাহকের হয়ে টিকেট খোলা

**হস্তান্তর** — চার ধরনের: ডিপার্টমেন্ট · এজেন্ট · টিম · ছেড়ে দেওয়া।
প্রতিটির পূর্ণ অডিট (কোথা থেকে কোথায়, কে, কেন, SLA-তে কী প্রভাব) ও
টাইমলাইনে প্রদর্শন। **বাইরে ফরওয়ার্ড** — ভেন্ডরের ইমেইলে, উত্তর
ট্র্যাকিং টোকেনসহ; উত্তর এলে তা ইন্টার্নাল নোট হিসেবে ফিরে আসবে (P4)।
**অনুলিপি (CC)** — অতিরিক্ত ব্যক্তি, যাঁরা ইন্টার্নাল নোট দেখেন না।

**অ্যাডমিন** — এজেন্ট (রোল, ডিপার্টমেন্ট সদস্যপদ, অবস্থা) · ডিপার্টমেন্ট
(ম্যানেজার, SLA, অটো-অ্যাসাইনমেন্ট কৌশল) · টিম · রোল ও ৪৫টি পারমিশনের
ম্যাট্রিক্স · হেল্প টপিক (টিকেট রাউটিংয়ের প্রথম ধাপ) · সিস্টেম সেটিংস ·
অ্যাক্টিভিটি লগ

**অটো-অ্যাসাইনমেন্ট** — ডিপার্টমেন্টের কৌশল অনুযায়ী: `manual` ·
`round_robin` (পালা করে) · `least_load` (যাঁর খোলা টিকেট কম)। ছুটিতে
থাকা এজেন্ট ও `max_open_tickets` সীমা মানা হয়।

**স্বয়ংক্রিয়** — টিকেট নম্বর (`YYMMDD-NNNN`) · SLA ডেডলাইন · এজেন্ট উত্তর
দিলে ঘড়ি থামা ও গ্রাহক উত্তর দিলে আবার চালু হওয়া · বন্ধ টিকেটে গ্রাহক উত্তর
দিলে নিজে থেকেই reopen · প্রতিটি পরিবর্তনের সিস্টেম এন্ট্রি ও অডিট লগ

### লকআউট প্রতিরোধ

অ্যাডমিন প্যানেলের কোনো পথেই সিস্টেম নিজের অ্যাডমিন হারায় না:

- নিজের অ্যাকাউন্ট নিজে নিষ্ক্রিয় বা মুছে ফেলা যায় না
- নিজের অ্যাডমিন অধিকার নিজে সরানো যায় না
- শেষ সক্রিয় সুপার অ্যাডমিনকে সরানো যায় না
- `Super Admin` রোলের পারমিশন বদলানো যায় না (নাম ও বিবরণ বদলানো যায়)
- ডিফল্ট ডিপার্টমেন্ট মোছা বা নিষ্ক্রিয় করা যায় না — আগে অন্যটিকে ডিফল্ট করতে হয়
- টিকেট আছে এমন ডিপার্টমেন্ট ও ব্যবহৃত রোল মোছা যায় না

## ইনস্টলেশন (XAMPP)

### ১. কোড রাখুন
`helpdesk/` ফোল্ডারটি `C:\xampp\htdocs\` এ কপি করুন।

### ২. Virtual Host (সুপারিশকৃত)

`C:\xampp\apache\conf\extra\httpd-vhosts.conf`-এ যোগ করুন:

```apache
<VirtualHost *:80>
    ServerName helpdesk.local
    DocumentRoot "C:/xampp/htdocs/helpdesk/public"
    <Directory "C:/xampp/htdocs/helpdesk/public">
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
```

`C:\Windows\System32\drivers\etc\hosts`-এ যোগ করুন:

```
127.0.0.1  helpdesk.local
```

Apache রিস্টার্ট দিন।

> **Virtual Host ছাড়াও চলবে** — সরাসরি `http://localhost/helpdesk/public/` খুলুন।
> রাউটার নিজে থেকেই সাব-ডিরেক্টরি বুঝে নেয়।

### ৩. php.ini

`C:\xampp\php\php.ini`-এ এগুলো চালু আছে কি না দেখুন (শুরুর সেমিকোলন সরিয়ে দিন):

```ini
extension=pdo_mysql
extension=mbstring
extension=openssl
extension=fileinfo
extension=gd
extension=zip
extension=curl

upload_max_filesize = 25M
post_max_size = 30M
max_execution_time = 120
memory_limit = 256M
```

> `extension=imap` **লাগবে না** — ইমেইল ফেচিং বিশুদ্ধ-PHP লাইব্রেরি দিয়ে হবে,
> কারণ PHP 8.4-এ `ext-imap` কোর থেকে সরিয়ে ফেলা হয়েছে।

### ৪. ব্রাউজারে ইনস্টলার চালান

`http://helpdesk.local/` খুলুন। তিন ধাপে ইনস্টল হবে:

1. **সার্ভার প্রস্তুতি** — সাতটি পরীক্ষা
2. **ডেটাবেস** — ডেটাবেস না থাকলে নিজেই তৈরি হবে, ৫১টি টেবিল ও ডিফল্ট ডেটা বসবে
3. **অ্যাডমিন অ্যাকাউন্ট** — সুপার অ্যাডমিন তৈরি, `.env` লেখা হবে

ইনস্টলের পর `/install` রুট নিজে থেকেই বন্ধ হয়ে যায়।

### ৫. Composer (ঐচ্ছিক — P4-এর আগে দরকার নেই)

```bash
composer install
```

Composer ছাড়াও অ্যাপ চলে, কারণ নিজস্ব PSR-4 অটোলোডার আছে। শুধু ইমেইল
পাঠানো/আনার ফিচারগুলোর জন্য PHPMailer ও php-imap লাগবে।

## ডেভেলপমেন্ট

```bash
# টেস্ট চালান (MySQL সার্ভার লাগে না)
php tests/run.php

# XAMPP ছাড়াই দ্রুত চালাতে
cp .env.example .env
php -S 127.0.0.1:8000 -t public
```

### টেস্ট কী যাচাই করে

| স্যুট | যা দেখে |
|---|---|
| `core_test.php` | QueryBuilder-এর SQL তৈরি ও ইনজেকশন প্রতিরোধ, Validator, Hash, Str, Env, Config |
| `schema_test.php` | ৫১টি টেবিলের ৮২টি ফরেন কী বিদ্যমান টেবিল/কলামে যাচ্ছে কি না, তৈরির ক্রম, কনস্ট্রেইন্টের নাম |
| `sanitizer_test.php` | ২০টি XSS পেলোড আটকায় কি না, বৈধ HTML ও বাংলা অক্ষর টিকে থাকে কি না |
| `ticket_test.php` | টিকেট তৈরি, নম্বর, SLA ঘড়ি থামা/চালু, reopen, নোটের দৃশ্যমানতা — আসল ডেটাবেসে |
| `http_test.php` | রাউট, CSRF, অনুমতি ও রেন্ডার হওয়া HTML — Router-কে সরাসরি ডেকে |
| `admin_test.php` | অ্যাডমিন CRUD, পারমিশন প্রয়োগ ও লকআউট-প্রতিরোধের প্রতিটি নিয়ম |
| `transfer_test.php` | চার ধরনের হস্তান্তর, SLA-র তিন আচরণ, অটো-অ্যাসাইনমেন্টের তিন কৌশল, ফরওয়ার্ড টোকেন, CC |

অনুবাদ করে মেমোরিতে চালায়, তাই সার্ভিসের আসল কোডপথই যাচাই হয়।

## ফরওয়ার্ডের উত্তর কীভাবে ফিরে আসে

```
১. টোকেন তৈরি:  fw_42_a1b2c3d4…
২. আউটগোয়িং মেইলে বসে —
     Reply-To:          support+fw_42_a1b2c3d4@company.com
     X-HelpDesk-Token:  fw_42_a1b2c3d4
     Subject:           [#250913-0042] মূল বিষয়
৩. উত্তর এলে MailFetcher (P4) টোকেন খোঁজে — এই ক্রমে:
     Reply-To → X-HelpDesk-Token → In-Reply-To → সাবজেক্টের [#নম্বর]
৪. উত্তরটি ইন্টার্নাল নোট হিসেবে টিকেটে যোগ হয় — গ্রাহক দেখেন না
```

`ExternalForwardService::findByToken()` ধাপ ৩ বাস্তবায়ন করে ও পরীক্ষিত;
মেইল পাঠানো ও আনার কাজ P4-এ যুক্ত হবে। এখন ফরওয়ার্ড `email_queue`-এ
জমা হয়, যেখান থেকে P4-এর sender সেটি তুলে নেবে।

## নিরাপত্তা

| ব্যবস্থা | বাস্তবায়ন |
|---|---|
| পাসওয়ার্ড | Argon2id (fallback bcrypt cost 12), লগইনে স্বয়ংক্রিয় rehash |
| সেশন | HttpOnly · SameSite=Lax · লগইনে `session_regenerate_id(true)` · নিষ্ক্রিয়তায় টাইমআউট |
| CSRF | সব POST/PUT/DELETE-এ বাধ্যতামূলক, `hash_equals()` |
| SQL ইনজেকশন | ১০০% prepared statement; টেবিল/কলাম/অপারেটর হোয়াইটলিস্টেড |
| XSS | সব আউটপুটে `e()` হেল্পার |
| ব্রুট ফোর্স | `login_attempts` — IP ও অ্যাকাউন্ট দুটোতেই সীমা |
| ফাইল | `storage/` ওয়েব রুটের বাইরে, র‍্যান্ডম নাম, permission যাচাই করে সার্ভ |
| আপলোড | এক্সটেনশন + ম্যাজিক বাইট যাচাই, চালানোযোগ্য টাইপ (`php`, `html`, `svg`…) সবসময় বাতিল |
| রিচ-টেক্সট | হোয়াইটলিস্ট স্যানিটাইজার — `on*`, `style`, `javascript:`, `<script>`, `<iframe>` কিছুই টেকে না |
| অডিট | সব সংবেদনশীল কাজ `activity_log`-এ |

`.env` কখনো git-এ যাবে না (`.gitignore`-এ আছে)। প্রোডাকশনে `APP_DEBUG=false` রাখুন।
