# পোস্ট আইডিয়া জেনারেটর 🎨

শিশুদের অনলাইন কোর্স পেইজের (বয়স ২.৫–১০ বছর) জন্য সোশ্যাল মিডিয়া পোস্ট আইডিয়া তৈরির একটি সহজ অ্যাপ। টার্গেট অডিয়েন্স — **মায়েরা, বয়স ২৫–৪৫**।

## যা করে

- **প্রতিবার নতুন পোস্ট** — এলোমেলো টেমপ্লেট + স্লট থেকে হাজারো ইউনিক কম্বিনেশন।
- **প্রতি পোস্ট আলাদা টোন** — আবেগঘন, গল্প, মজার, তথ্যমূলক, প্রশ্ন, সচেতনতা, জরুরি অফার, অভিভাবকের মতামত, প্যারেন্টিং টিপস, উৎসব/মাইলফলক।
- **মানবিক অনুভূতি** — মায়েদের বন্ধুর মতো আন্তরিক, সহানুভূতিশীল বাংলা ভয়েসে লেখা।
- **উদ্দেশ্য অনুযায়ী** — সচেতনতা / এনগেজমেন্ট / ভর্তি-বিক্রি / ব্র্যান্ডিং ফিল্টার।
- এক ক্লিকে **কপি**, একটি পোস্ট **আবার বানানো**, বা **সব কপি** করা।
- হ্যাশট্যাগসহ রেডি টেক্সট, ডার্ক/লাইট মোড, মোবাইল রেসপন্সিভ।

## কীভাবে চালাবেন

কোনো ইনস্টল বা সার্ভার লাগে না — এটি সম্পূর্ণ স্বয়ংসম্পূর্ণ একটি HTML ফাইল।

```
index.html ফাইলটি যেকোনো ব্রাউজারে খুলুন।
```

তারপর:
1. **পোস্টের উদ্দেশ্য** ও **টোন** বেছে নিন (অথবা "মিক্সড" রাখুন)।
2. কতগুলো পোস্ট চান বেছে নিন → **পোস্ট বানান** চাপুন।
3. পছন্দের পোস্ট **কপি করুন**, পেইজের নাম/অফার/ছবি যোগ করে পাবলিশ করুন।

## নোট

জেনারেট হওয়া পোস্টগুলো রেডি আইডিয়া — পাবলিশের আগে আপনার পেইজের নাম, নির্দিষ্ট অফার ও ছবি যোগ করে নিন।
